## ДЗ 1 коротко

Задача — рекомендовать треки, **которых пользователь раньше не слышал**: всё знакомое
исключается из кандидатов. Датасет — [Yambda-50M](https://huggingface.co/datasets/yandex/yambda)
(`yandex/yambda`, вариант `flat/50m`), подвыборка 3 000 пользователей × каталог 10 000 треков
= 1 966 410 взаимодействий. Основная метрика, зафиксированная до подбора, — NDCG@10; вторая —
Recall@10.

| модель | NDCG@10 | Recall@10 |
|---|---:|---:|
| item-based kNN | 0,06731 | 0,02698 |
| FM с аудиоэмбеддингами | 0,07250 | 0,02816 |
| iALS | 0,07278 | 0,02936 |
| iALS со своим целевым сигналом | 0,07501 | 0,02994 |
| **EASE** | **0,07836** | **0,03032** |

Все пять моделей написаны с нуля на numpy/scipy. Подробности, отчёт и воспроизведение —
в [hw1](hw1): [`hw1/DATA.md`](hw1/DATA.md) — датасет и способ отбора подвыборки,
[`hw1/experiments.ipynb`](hw1/experiments.ipynb) — основной ноутбук,
[`hw1/REPORT.md`](hw1/REPORT.md) — отчёт, [`hw1/LIMITATIONS.md`](hw1/LIMITATIONS.md) —
ограничения постановки.
