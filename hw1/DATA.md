## Датасет

**Название:** Yambda-50M — вариант `flat/50m` датасета `yandex/yambda`.

**Ссылка на первоисточник:** https://huggingface.co/datasets/yandex/yambda

Лицензия Apache 2.0, доступ без токена. Обезличенные события сервиса Яндекс Музыка:
прослушивания, лайки, дизлайки и их отмены, плюс метаданные артистов и альбомов и
аудиоэмбеддинги треков. Датасетов из семинаров курса и запрещённых заданием
(MovieLens, Netflix Prize, Last.fm) работа не использует.

## Способ получения

```bash
bash tools/download_data.sh                                   # 471 МБ в data/raw
python -I tools/build_subsample.py data/raw                   # подвыборка
python -I tools/checks/f4_export_embeddings.py data/raw        # аудиовекторы каталога
```

Данные в репозиторий не загружаются (см. `.gitignore`). Полный файл эмбеддингов Yambda
весит 13,8 ГБ и целиком не нужен: скрипт читает его по сети с отбором колонок и оставляет
векторы только для треков каталога (9 МБ). Если данные уже скачаны в другое место, путь
задаётся переменной окружения `YAMBDA_DATA` — см. `models/common.py`, функция `data_dir()`.

## Объём: исходный и итоговый

| | события | пользователи | треки |
|---|---:|---:|---:|
| исходный датасет (`flat/50m`) | 46 467 212 прослушиваний | 10 000 | 934 057 |
| в таблице прослушиваний | — | 9 238 | 877 168 |
| **итоговая подвыборка** | **1 966 410 взаимодействий** | **3 000** | **10 000** |

Пользователи и треки исходного датасета посчитаны по всем типам событий; в самой таблице
прослушиваний их меньше.

**Что считается взаимодействием.** Уникальная пара (пользователь, трек) — именно пары
получают на вход все пять моделей, матрица строится по ним. Повторные прослушивания одной
пары не отдельные взаимодействия, а сигнал внутри одной: из них собираются число повторов
и качество первого прослушивания. Строк событий в подвыборке 7 969 893, то есть примерно
вчетверо больше, чем пар.

## Способ отбора подвыборки

Воспроизводимо, сид 42, скрипт `tools/build_subsample.py`:

1. **Фильтр пользователей.** Из 10 000 убраны 762 без прослушиваний, 125 холодных и
   36 «перелистывающих» (почти все события — скипы); оставлены те, у кого не меньше
   5 прослушиваний в сутки 0…279. Остался пул 9 055, из него случайно отобраны 3 000.
2. **Каталог.** Топ-10 000 треков по числу слушателей пула, отобранный **только по истории
   до тестового окна**, сортировка с `item_id` для однозначности. Хвост Yambda очень
   длинный: половину треков знает один человек, и без ограничения каталога матрица не
   укладывается ни в коридор задания, ни в память под EASE.
3. **Цена этого отбора** известна и измерена: достижимыми остаются 34,8 % релевантных
   новинок тестового окна. Подробно — в `LIMITATIONS.md`.

Обоснование каждого шага — в блоках разведочного анализа `eda/01-sanity` … `eda/09-features-leakage`,
проверка собранной подвыборки — в `eda/08-subsample`.

## Поля, которые используются

| поле | смысл |
|---|---|
| `uid` | обезличенный пользователь |
| `item_id` | трек |
| `timestamp` | время события, единица — **одна секунда** |
| `played_ratio_pct` | какую долю трека проиграли, в процентах |
| `is_organic` | нашёл пользователь трек сам (1) или по рекомендации сервиса (0) |
| `track_length_seconds` | длительность трека |
| `artist_id`, `album_id` | метаданные из отдельных таблиц соответствий |
| `normalized_embed` | аудиовектор трека, 128 чисел, норма 1 |

**Про единицу времени.** Карточка датасета говорит о 5-секундной гранулярности, и это легко
прочитать как «единица равна пяти секундам». Единица — одна секунда, кратность пяти относится
к округлению: суточный ритм виден только при периоде 86 400, а интервал между соседними
прослушиваниями равен проигранным секундам (медиана отношения 1,02). Горизонт данных —
301 сутки, ровно 43 недели. Разбор — в `eda/02-time`.

**Что рекомендуем и что считается релевантным** — в `README.md` этой папки и в разделах 1 и 3
ноутбука `experiments.ipynb`.
